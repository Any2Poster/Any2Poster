# Contributing to Any2Poster

We welcome contributions! Please follow these guidelines.

## Reporting Issues
Open a GitHub Issue with a minimal reproducible example and your OS,
Python version, and model configuration from your .env file.

## Pull Requests
1. Fork the repository
2. Create a feature branch: git checkout -b feature/your-feature
3. Ensure ruff check . passes with no errors
4. Add or update tests in any2poster/tests/ for any changed logic
5. Open a PR against main with a clear description of what changed and why

## Code Style
We use ruff with line-length = 100. Run ruff check . --fix before committing.
